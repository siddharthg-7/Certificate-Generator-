────────────────────────────────────────────────────────────────────────────────

All coordinates use RELATIVE values from 0.0 to 1.0:

  • 1.0 = End (Right for X, Bottom for Y)

ZONE DEFINITIONS:

Zone 1 - CENTER MIDDLE (Default, Priority 1):
  x_range: [0.25, 0.75]  → Centered horizontally, 50% width

COMMON ADJUSTMENTS:

Move Text UP:

Move Text DOWN:
  Before: "y_range": [0.45, 0.60]

Move Text LEFT:

Move Text RIGHT:

Make Zone WIDER (more flexible):
  Before: "x_range": [0.25, 0.75]  (50% width)

PIXEL TO RELATIVE CONVERSION:
────────────────────────────────────────────────────────────────────────────────

Formula:
  relative_x = pixel_x / image_width
  relative_y = pixel_y / image_height

Example (Certificate: 2000px × 1500px):
  Desired position: (1000px, 750px)
  
  Calculation:
    x = 1000 / 2000 = 0.50 (center)
    y = 750 / 1500 = 0.50 (center)
  
  Configuration:
    "x_range": [0.45, 0.55]  ← ±0.05 around 0.50
    "y_range": [0.45, 0.55]  ← ±0.05 around 0.50

HUMANIZATION SETTINGS:
────────────────────────────────────────────────────────────────────────────────

Natural Variations (Recommended):
  "humanize_offset": true
  "offset_range": [-5, 5]
  Result: Each certificate unique, ±5 pixels variation

Subtle Variations:
  "humanize_offset": true
  "offset_range": [-2, 2]
  Result: Slight differences, ±2 pixels variation

Exact Placement:
  "humanize_offset": false
  "offset_range": [0, 0]
  Result: All certificates identical

Strong Variations:
  "humanize_offset": true
  "offset_range": [-10, 10]
  Result: More noticeable differences, ±10 pixels


FONT SIZE ADAPTATION:
────────────────────────────────────────────────────────────────────────────────

Default: "font_size_range": [60, 90]

Name Length → Font Size:
  ≤ 10 chars  → 90px (max)      Example: "John Doe"
  11-15 chars → 75px (-30%)     Example: "Alexander Smith"
  16-20 chars → 65px (-60%)     Example: "Dr. Christopher Lee"
  > 20 chars  → 60px (min)      Example: "Prof. Alexander Hamilton III"

Plus random variation: ±2px for natural look


PRIORITY SYSTEM:
────────────────────────────────────────────────────────────────────────────────

How it works:
  Score = Image_Variance × Priority_Number
  
  Lower score = Better zone (selected)

Example:
  Zone 1: variance=100, priority=1 → score=100 ✓ SELECTED
  Zone 2: variance=80,  priority=2 → score=160
  Zone 3: variance=90,  priority=3 → score=270

The system automatically picks the zone with the lowest score!
